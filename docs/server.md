# وقتی سرور اضافه شد

مرز فعلی `src/lib/gateway.js` است (`load` و `save`). برای سرور:

| موضوع | سمت سرور |
| --- | --- |
| ورود و حساب | احراز هویت؛ هر رکورد `ownerId` |
| دسترسی | هر کاربر فقط داده‌ی خودش (row-level) |
| قوانین | همون `src/lib/domain` دوباره روی سرور اجرا بشه؛ به ورودی کلاینت اعتماد نشه |
| id و زمان | `ctx.newId` و `ctx.now` از سرور |
| همگام‌سازی | ذخیره‌ی کلِ state جاش رو به عملیات رکوردی می‌ده، با تشخیص تداخل |
| مهاجرت | آپلود یک‌باره‌ی پشتیبان محلی |
| پول | عدد صحیح + کد واحد روی هر رکورد (الان واحد فقط برچسبه) |
| پشتیبان | خودکار سمت سرور |

نکته‌ها:
- `gateway` الان هم‌زمانه؛ نسخه‌ی سروری async می‌شه و `AppContext` باید حالت بارگذاری و خطای شبکه داشته باشه.
- کارفرما همچنان رکورده؛ حساب کارفرما تصمیم محصولی جداست.
