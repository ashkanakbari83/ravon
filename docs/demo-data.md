# داده‌ی نمونه

- سازنده: `src/data/seed.js` با PRNG قطعی. تاریخ‌ها نسبت به روز بارگذاری (`meta.demoAnchor`) ساخته می‌شن تا همیشه تازه به نظر بیان.
- همه‌ی رکوردها `demo: true` و id با پیشوند `demo-`.
- «پاک‌کردن نمونه» فقط نمونه رو حذف می‌کنه. اگه روی پروژه‌ی نمونه پرداخت، زمان یا تایمر واقعی ثبت شده باشه، اون پروژه به داده‌ی واقعی تبدیل می‌شه و می‌مونه.
- نمونه‌ی تازه: رکورد با `release: N` اضافه کن و `SEED_RELEASE = N`. فقط همون رکوردها، یک‌بار و با id، اضافه می‌شن؛ چیزی بازنویسی یا زنده نمی‌شه.
- تست‌ها از `cleanSeed()` در `tests/unit/helpers.js` شروع می‌کنن.
- همه‌ی اسم‌ها ساختگی‌ان.
