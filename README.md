# رَوون / RAVON

پنل شخصی، سبک و سریع برای پروژه‌های فریلنسری ادیت و تولید محتوا: پروژه و کارفرما، وضعیت تحویل، زمان کار، دریافتی‌ها و گزارش.
فارسی و راست‌به‌چپ، تاریخ شمسی، PWA (آفلاین). **بدون سرور و حساب کاربری؛ داده فقط روی همین مرورگر.**

## اجرا

نیاز: Node ۲۲ یا بالاتر.

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # خروجی در dist/
npm run preview
```

## کار سریع

- حذف و تغییر وضعیت تأیید نمی‌پرسن؛ تا ۷ ثانیه «برگردون» داری. (پاک‌کردن همه‌چیز و بازیابی پشتیبان هنوز تأیید می‌خوان.)
- دسکتاپ: `N` پروژه‌ی جدید، `/` جست‌وجو (روی کیبورد فارسی هم کار می‌کنه).
- نصب روی دستگاه از «تنظیمات»، وقتی مرورگر اجازه بده؛ در iOS راهنماش همون‌جاست.

## داده‌ی نمونه

حساب و رمزی در کار نیست. بار اول از صفحه‌ی خوش‌آمد (یا بعداً از «تنظیمات») یکی رو انتخاب کن:

| نمونه | محتوا |
| --- | --- |
| شلوغ | ۲۴ کارفرما، حدود ۱۴۰ پروژه در ۱۴ ماه |
| خلوت | ۶ کارفرما، ۱۷ پروژه |

## تست

```bash
npm test             # تست واحد (node --test)
npm run test:e2e     # Playwright: موبایل و دسکتاپ، ناوبری، چیدمان، آفلاین
npm run shots        # اسکرین‌شات همه‌ی صفحه‌ها (بعد از build)
```

بار اولِ e2e روی سیستم تازه: `npx playwright install chromium`.

## ساختار

```
src/lib/domain   قوانین کسب‌وکار؛ تابع خالص (db, ...) → { ok, db } | { ok: false, error }
src/lib          تقویم شمسی، قالب‌بندی، ذخیره (gateway)، سازنده‌ی xlsx
src/data         داده‌ی نمونه‌ی قطعی
src/pages · components · modals · hooks · context
src/i18n         هر کلید: [فارسی, انگلیسی]
src/styles       tokens → base → components → pages → calm
```

## محدودیت‌های فعلی

- داده فقط روی یک دستگاه است؛ همگام‌سازی نداریم و پاک‌شدن داده‌ی مرورگر یعنی از دست رفتن داده (پشتیبان بگیر).
- پرداخت‌ها فقط «ثبت» می‌شن؛ هیچ تراکنشی انجام نمی‌شه.
- تغییر واحد پول فقط برچسب رو عوض می‌کنه.
- انگلیسی در متن‌ها و ساختار آماده‌ست، ولی هنوز کلیدی برای انتخابش نیست و تقویم همیشه شمسیه.
- یادآوری، PDF و چندکاربره عمداً در MVP نیست.
